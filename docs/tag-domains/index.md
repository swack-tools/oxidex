# Tag Domains

OxiDex groups ExifTool's tag definitions into six domains, one per `oxidex-tags-*` crate. The pages below list them.

## Domain Categories

### [Core](./core.md)
Fundamental metadata present in most files: file properties, timestamps, format identification, and basic technical information.

### [Camera](./camera.md)
Camera-specific metadata including exposure settings, lens information, focus data, flash settings, and manufacturer-specific maker notes.

### [Image](./image.md)
Image technical metadata: dimensions, resolution, color space, compression, and pixel-level information.

### [Media](./media.md)
Audio and video metadata: codecs, duration, bitrates, channels, and streaming information.

### [Document](./document.md)
Document metadata: author, title, creation date, revision history, and document-specific properties for PDFs, Office files, etc.

### [Specialty](./specialty.md)
Specialized metadata domains: GPS/location data, XMP metadata, IPTC news metadata, and format-specific extensions.

## What these pages are

Each domain page lists ExifTool tag *definitions* by ExifTool table (for
example `Exif::Main` or `Canon::CameraSettings`). The six pages together
hold 931 tables and 16,684 definitions. They are generated by
`just docs-generate-tags` (`oxidex-tags/examples/render_domain.rs`) from the
YAML the `oxidex-tags-*` crates embed, and were last regenerated in #820.
Do not edit them by hand.

A definition records that ExifTool documents a tag. It says nothing about
whether OxiDex extracts it; [ExifTool parity](/guide/exiftool-parity)
covers that. In OxiDex's output, tags carry ExifTool's family 1 group, for
example `IFD0:Make`, `ExifIFD:ISO`, `GPS:GPSLatitude` or `Canon:LensModel`,
and not the table name used here.
